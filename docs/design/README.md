# UI design reference

[`speaker-ui-reference.html`](speaker-ui-reference.html) is a self-contained page with screenshots of every screen
of the web app: iPhone, iPad, desktop, Android phone and Android tablet, in light and dark, English and Thai.
Download it and open it in a browser (it is too large for GitHub's preview). Use it as a starting point when
designing new screens or porting the app.

The screenshots come from the real app running with placeholder data (`192.0.2.x`, `example.com`, made-up names),
so nothing in them is a real speaker, host or person. They show the app as it was when the file was last updated;
the code is the source of truth.
